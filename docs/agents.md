# docs — 文档目录（强制）

在实现功能、修改 `MetaBundle` / publisher 契约、调整部署或客户端交互前，请先阅读本目录及根 README。

## 文档目录（强制）

| 路径 | 用途 |
|------|------|
| **`docs/PRD/`** | 页面、字段、主流程 |
| **`docs/database/`** | JSON schema 与三方接口契约 |
| **`docs/domains/`** | 架构、用例、需求分析、修改记录 |
| **`docs/features/`** | 功能域流程（七章模板，中文文件名） |
| **`docs/superpowers/`** | 历史 design / implementation plan |
| **禁止** | 在 `docs/` 根目录新增说明类 Markdown（`agents.md`、`deploy-aliyun.md` 除外） |

**命名**：`docs/features/`、`docs/PRD/` 内 Markdown **一律中文文件名**。例外：`README.md`、`agents.md`、`INDEX.md`。
