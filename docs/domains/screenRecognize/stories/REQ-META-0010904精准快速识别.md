# 精准快速识别

> 需求编号：REQ-META-001 | 类型：需求 | 日期：2026-09-04 | 修复人：zhangyu10 | 模块域：screenRecognize

## 1. 背景与问题

能裁到棋子但经常认成别的英雄。12×12 去均值 SAD 对同费用相似立绘区分度不够；JS 再匹配一遍浪费 bridge。

## 2. 需求/问题描述

本机模板匹配要更准且仍快：费用先验、24×24 NCC + HSV、近邻拒绝、两帧投票、原生只回 id。不上传截图，OCR/Vision 仍为 P2。

## 3. 分析与诊断

模板是方图，局内是卡面/六边形。匹配算法过弱；空余算力足够升级特征。模块 `android/` 曾被根 gitignore 整目录忽略。

## 4. 解决方案

见 [架构](../实时识别与AI推荐.md)。gitignore 改为只忽略 Expo prebuild。
