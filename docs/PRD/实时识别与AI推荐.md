## 主流程

```text
启动 App → 同步 Meta bundle（图鉴含 24×24 指纹）
    → 设置：Meta URL / 开启对局识别（悬浮窗 + 系统录屏）
    → 金铲铲全屏对局，右上角悬浮球
    → 抓帧前隐藏浮层 → 全屏裁商店立绘区 + 棋盘格心
    → 费用色先验 + 24×24 NCC + HSV；近邻 margin 不够则空
    → 原生只回 id/name/confidence；两帧投票后写入 ownedIds
失败：拒绝录屏/悬浮窗或游戏禁录屏 → 仅手动点选
```

## 页面分组一览

| 组 | 页面 | 为何放一起 | 字段位合计 |
|----|------|------------|------------|
| 对局 | 点选 | 棋子选择、识别状态、推荐同一决策面 | 16 |
| 设置 | 设置 | URL、识别开关、授权说明 | 10 |

## 跨页同名字段对照

| 字段 | 点选 | 设置 | 类型 |
|------|------|------|------|
| ownedIds | ✅ | — | `string[]` |
| shopIds | ✅ | — | `string[]` |
| bundle.champions | ✅ | ✅ | Champion[]（含 fingerprint/cost） |
| recognizeEnabled | ✅ | ✅ | boolean |

## 各页字段明细

### 点选

| 区块 | 字段 | 说明 |
|------|------|------|
| 识别条 | 状态 / 置信度 / 清空 / 跟随识别 | 两帧投票后才改 ownedIds |
| 棋子栅格 | 按费用点选 | 与识别结果双向同步 |

### 设置

| 字段 | 说明 |
|------|------|
| Meta URL | `http(s)://host/v1/meta` |
| 对局识别开关 | 悬浮窗 + 系统录屏 |
| 识别引导 | 金铲铲全屏，点右上角悬浮球 |

## 配置字典组

- 识别布局比例、24×24 / NCC / HSV / margin 为客户端常量。
- 默认不把截图送给 Vision；商店中文名 OCR 仍为 P2。
